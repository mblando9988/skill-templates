# skill-templates

My starter templates for skills.

Contents:

- `templates/skill-md-template.md` — SKILL.md starter
- `templates/script-template.py` — Python skill script starter
- `templates/github-workflow-skill-ci.yml` — drop into `.github/workflows/skill-ci.yml` for skill CI
- `references/condensed.md` — single-file condensed guide (frontmatter, freedom levels, lenses, questions, scripts, spec, review, testing)

## Use

Copy what you need into a new skill directory and fill in the `{{placeholders}}`.
